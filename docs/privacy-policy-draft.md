# Privacy policy draft

This application does not require an account or GPS location. The current implementation stores selected region, calculator inputs, and cached API responses locally on the device. Price requests are sent to the configured backend, which may record standard operational request logs. No advertising or payment SDK is included.

The backend includes optional device registration and push-token storage, but the mobile client does not activate it in this build. Before enabling that flow, this document must describe installation identifiers, push tokens, purpose, retention, deletion controls and Firebase as a processor.

Before publishing, the owner must provide a legal operator name, contact address, public privacy-policy URL, retention periods and applicable rights/contact process. This draft is not a substitute for review of the final deployed data flow.
